# Research

Interner Arbeitsbereich für Content-Recherche.

Regeln:
- pro Artikel ein Ordner mit demselben Slug wie der finale Beitrag;
- Erkenntnisse paraphrasieren und extrahieren;
- keine längeren fremden Textpassagen archivieren;
- Primärquellen für zentrale Fakten bevorzugen;
- `curation.md` enthält das verbindliche Human Gate.
